# GiftMoneyCalc

## Platform
앱인토스 (Vite + React + TDS)

## One-liner
관계·지역·물가를 반영해 축의금·부의금 적정 금액을 알려주는 계산기

## Problem
결혼식·장례식 축의금·부의금 액수를 정할 때마다 검색하고 지인에게 물어봐야 하는 불편함이 반복된다. 명확한 기준이 없어 매번 고민하고 커뮤니티에 물어본다.

## Target Users
20-40대 경조사 참석 빈도가 높은 직장인 전체

## Core Features
1. 관계·친밀도·행사 종류 입력 후 적정 금액 산출
2. 지역·물가 반영 보정 옵션
3. 누구에게 얼마 줬는지 히스토리 기록
4. 평균·분포 통계 상세 리포트(리워드 광고 후 공개)
5. 결과 공유 카드뉴스 생성
6. 부의금·돌잔치·개업식 등 경조사 유형 확장

## Monetization
- Model: ads
- Estimated MRR: 약 241,000원(월 순수익, DAU 2,500명 가정)
- Reasoning: 배너+리워드 광고 결합. DAU 2,500명 × 96.39원 ≈ 월 241,000원. 결혼·명절 시즌 스파이크로 공유 바이럴 유입은 기대되나, 이벤트 발생 시에만 재방문하는 낮은 리텐션 구조라 실제 DAU는 시즌 편차가 클 수 있음.
